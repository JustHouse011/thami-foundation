# About image assets

Created using the built-in imagegen tool, then resized and encoded locally as WebP using browser canvas. These are fictional editorial scenes, not documentary evidence of Foundation events, participants or housing services. They must not be used as an authentic portrait of Thami Kotlolo.

Saved assets: `public/images/about/about-hero.webp`, `about-community.webp`, `about-thingolezwe.webp`, and `about-belonging.webp`, each with a `-640.webp` responsive variant. All are centrally configured in `src/data/about.ts`.

The leadership section deliberately uses a clearly labelled typographic placeholder. Set `leadership.portrait` only after an approved authentic photograph is supplied.
